Objective

Implement automatic OAuth2 token refresh logic to handle expired access tokens transparently. The system should detect 401 responses, trigger a refresh token exchange, and retry the original request.

Acceptance Criteria

  • Intercept 401 responses from protected endpoints
  • Store refresh token securely in httpOnly cookie
  • Retry failed request with new access token
  • Handle refresh token expiration gracefully
  • Add unit tests for all refresh scenarios

Technical Context

Use the existing auth/middleware.ts as the interception point. The token store is in services/token-store.ts.

interface TokenRefreshConfig {
  accessTokenTtl: number;
  refreshTokenTtl: number;
  retryOn401: boolean;
  maxRetries: number;
}
